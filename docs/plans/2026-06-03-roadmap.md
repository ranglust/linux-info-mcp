# Item 2 — error_kind taxonomy (P0)

**Goal.** Normalize every SSH/command failure into a single `error_kind` field so
the model knows whether to retry, switch host, escalate privilege, or give up —
instead of guessing from raw stderr.

**Kinds.** `ok | timeout | auth | dns | unreachable | not_found | privilege | nonzero`

**Current state.** `run_ssh` sets `exit_code=124` + logs `outcome=timeout` on
timeout; `outcome=ok|nonzero` otherwise (logged, *not* returned in the result
dict). `_annotate_privilege` sets `privilege_error=True` on nonzero+stderr match.
Result dicts already carry `exit_code` (int) and `stderr` (decoded str) — enough
to classify centrally with zero per-tool churn.

**Design.** Add a pure classifier and call it from the same central point that
already annotates privilege, so both the single-host and multi-host paths get it
(both already route through `_annotate_privilege`).

Classification precedence (first match wins):

1. `exit_code == 0` → `ok`
2. `exit_code == 124` → `timeout` (our kill sentinel from `run_ssh`)
3. stderr matches auth regex → `auth`
4. stderr matches dns regex → `dns`
5. stderr matches unreachable regex → `unreachable`
6. `exit_code == 127` or stderr "command not found" → `not_found`
7. stderr matches existing `_PRIV_ERR_RE` → `privilege`
8. else → `nonzero`

Rationale for order: ssh-transport failures (auth/dns/unreachable) surface on
ssh's own exit 255 and are checked before remote-command failures
(not_found/privilege) which exit 1/127 from the remote shell.

**Files.**

`linux_info_mcp/server.py` — add regexes + classifier near `_PRIV_ERR_RE`:

```python
_ERR_AUTH_RE = re.compile(
    r"permission denied \(|authentication failed|too many authentication failures"
    r"|publickey,|host key verification failed",
    re.IGNORECASE,
)
_ERR_DNS_RE = re.compile(
    r"could not resolve hostname|name or service not known"
    r"|nodename nor servname|temporary failure in name resolution",
    re.IGNORECASE,
)
_ERR_UNREACH_RE = re.compile(
    r"connection refused|no route to host|network is unreachable"
    r"|connection timed out|operation timed out|connection closed",
    re.IGNORECASE,
)
_ERR_NOTFOUND_RE = re.compile(r"command not found", re.IGNORECASE)


def classify_error(exit_code, stderr) -> str:
    if isinstance(exit_code, int) and exit_code == 0:
        return "ok"
    if exit_code == 124:
        return "timeout"
    s = stderr if isinstance(stderr, str) else ""
    if _ERR_AUTH_RE.search(s):
        return "auth"
    if _ERR_DNS_RE.search(s):
        return "dns"
    if _ERR_UNREACH_RE.search(s):
        return "unreachable"
    if exit_code == 127 or _ERR_NOTFOUND_RE.search(s):
        return "not_found"
    if _PRIV_ERR_RE.search(s):
        return "privilege"
    return "nonzero"
```

Extend `_annotate_privilege` (keep its name + `privilege_error` for back-compat;
just add `error_kind`):

```python
def _annotate_privilege(result: dict) -> dict:
    if not isinstance(result, dict):
        return result
    ec = result.get("exit_code")
    stderr = result.get("stderr")
    if isinstance(ec, int):
        result["error_kind"] = classify_error(ec, stderr)
        if ec != 0 and isinstance(stderr, str) and _PRIV_ERR_RE.search(stderr):
            result["privilege_error"] = True
    return result
```

Note: `error_kind` is set on **every** result that has an int `exit_code`
(including `ok`), so callers can branch uniformly. `privilege_error` stays for
existing consumers (redundant with `error_kind=="privilege"`; remove in a future
breaking change, not now).

**Tests** (`tests/test_server.py`):

- `classify_error` unit: exit 0 → ok; exit 124 → timeout; each stderr regex →
  its kind (use real strings: `"Permission denied (publickey)."`,
  `"Could not resolve hostname foo: Name or service not known"`,
  `"ssh: connect to host x port 22: Connection refused"`,
  `"bash: iostat: command not found"`, exit 127 → not_found,
  `"Operation not permitted"` → privilege); generic nonzero → nonzero.
- precedence: stderr with both auth-ish and privilege-ish text → auth (checked first).
- integration: single-host result carries `error_kind`; nonzero privilege case
  carries both `error_kind=="privilege"` and `privilege_error=True`.
- multi-host: each per-host result carries `error_kind`.

**Acceptance.** Every tool result (single + per-host) gains `error_kind`; no
per-tool file changes; existing `privilege_error` behavior unchanged.

**Risk.** Regex over-match. Mitigated by anchored, case-insensitive, well-known
OpenSSH strings + unit tests with real adversarial stderr.

# Item 1 — SSH connection-mux default (P0)

**Goal.** Kill the per-call SSH handshake tax (TCP + TLS/cert + node dial on every
tool call) by defaulting to OpenSSH connection multiplexing. First call to a host
opens a master; subsequent calls ride the mux socket.

**Current state.** `_ssh_argv()` (`ssh.py:16`) returns `shlex.split(LINUX_INFO_SSH_CMD)`
or `["ssh"]`. No mux. Multi-host fan-out and repeated single-host calls each pay a
fresh handshake.

**Design.** When `LINUX_INFO_SSH_CMD` is **unset**, inject ControlMaster options.
When it is set, the user owns the full argv (override wins — unchanged). Add an
opt-out `LINUX_INFO_SSH_MUX` for users who want plain `ssh` without setting a full
command. Control socket lives under `$TMPDIR` (respects the global no-`/tmp` rule
via `tempfile.gettempdir()`, which honors `TMPDIR`), keyed by `%C` (fixed-length
connection hash — avoids the ~104-char socket-path limit that `%r@%h:%p` can blow).

`linux_info_mcp/ssh.py`:

```python
import tempfile  # add to imports

_MUX_OFF = {"0", "false", "no", "off"}


def _mux_opts() -> list[str]:
    if os.environ.get("LINUX_INFO_SSH_MUX", "").strip().lower() in _MUX_OFF:
        return []
    ctl = os.path.join(tempfile.gettempdir(), "lim-%C")
    return [
        "-o", "ControlMaster=auto",
        "-o", f"ControlPath={ctl}",
        "-o", "ControlPersist=60s",
    ]


def _ssh_argv() -> list[str]:
    cmd = os.environ.get("LINUX_INFO_SSH_CMD", "").strip()
    if cmd:
        return shlex.split(cmd)
    return ["ssh", *_mux_opts()]
```

(Behavior change vs current: the bare fallback is now `["ssh", *_mux_opts()]`
instead of `["ssh"]`.)

**Tests** (`tests/test_ssh.py`):

- env unset → `_ssh_argv()` contains `ControlMaster=auto`, a `ControlPath=` under
  `tempfile.gettempdir()`, and `ControlPersist=60s`.
- `LINUX_INFO_SSH_CMD` set (e.g. `"ssh -F /x"`) → returned verbatim via shlex; no
  injected mux opts.
- `LINUX_INFO_SSH_MUX=0` (env cmd unset) → `["ssh"]`, no mux opts.
- ControlPath uses `%C` (assert literal `lim-%C` in the path).
- monkeypatch env; no leak between tests.

**Acceptance.** Out of the box (no env config) repeated calls to the same host
reuse one connection. Power users keep full control via `LINUX_INFO_SSH_CMD`.

**Docs.** README: perf note + the two env vars. SPEC: note mux default + socket
location + the `%C`/`ControlPersist` rationale.

**Risk.** Stale master after a network change → bounded by `ControlPersist=60s`.
Requires OpenSSH ≥ 6.7 for `%C` (universally true today). Each host gets its own
master (distinct `%C`); fan-out still amortizes across repeated same-host calls.

# Item 5 — output_mode / parsed (P3)

Full design was locked in `docs/plans/2026-06-03-output-mode.md` plus four
decisions taken this session. Summary of the locked decisions:

- **Truncated output is not parsed.** `truncated=True` → `parse_status="skipped_truncated"`,
  keep stdout (even in `parsed` mode). "Big data sets, do not parse."
- **Strict lowercase only.** `validate_output_mode` accepts exactly `raw`/`parsed`/
  `both`; `"Raw"`/`"PARSED"` → `ValueError`. No normalization. Env is `.strip()`-ed
  then strict-matched.
- **Log `output_mode` + `parse_status`.** `log_extra["output_mode"]` always;
  `parse_status` added when single-host + non-raw + present.
- **`parse_free` returns a list of samples.** Always `list[dict]`, one entry per
  sample, each `{"mem": {...}, "swap": {...}}`. Single call → `[{...}]`. New sample
  starts on each `Mem:` line. Handles `-s/-c` multi-sample naturally.

`parse_status` value set: `ok | unsupported | skipped_nonzero | skipped_truncated
| error:<ExcName>` (raw mode sets none — zero behavior change).

`apply_output_mode` precedence (final):

```
raw            → pop "parsed", return (no parse_status)
exit_code != 0 → skipped_nonzero, keep stdout
truncated      → skipped_truncated, keep stdout
parser is None → unsupported, keep stdout
stdout not str → unsupported, keep stdout
parse ok       → set parsed, parse_status=ok; mode==parsed drops stdout
parse raises   → error:<Exc>, keep stdout
```

# Item 3 — triage meta-tool (P1, highest user value)

**Goal.** One SSH round-trip that returns a prioritized health summary:
`{warnings, facts}`. Copies the `host_facts` bundle pattern (fixed `sh -c` script,
no interpolation, sectioned output, pure parser).

**New file** `linux_info_mcp/tools/triage.py`.

**Probes (fixed `_SCRIPT`, each `2>/dev/null || true`):**

| Section | Command | Drives |
|---------|---------|--------|
| `loadavg` | `cat /proc/loadavg` | load1/5/15 |
| `nproc` | `nproc` | load-vs-cpu ratio |
| `meminfo` | `grep -E '^(MemTotal\|MemAvailable\|SwapTotal\|SwapFree):' /proc/meminfo` | low memory, swap pressure |
| `df` | `df -P -l -x tmpfs -x devtmpfs` | per-mount use% |
| `failed_units` | `systemctl --failed --no-legend --plain` | failed services |
| `psi_cpu/mem/io` | `cat /proc/pressure/{cpu,memory,io}` | stall pressure |
| `oom` | `dmesg 2>/dev/null \| grep -iE 'out of memory\|killed process' \| tail -n 5` | recent OOM (best-effort; empty if dmesg restricted) |

`build_remote_cmd_triage()` → `"LC_ALL=C sh -c " + shlex.quote(_SCRIPT)` (mirrors
`facts.py:59`; AGENTS rule against `sudo sh -c` respected — no sudo wrapping the
script; `dmesg` degrades to empty when `kernel.dmesg_restrict` blocks it).

**Pure parsers + thresholds (named constants):**

```python
LOAD_PER_CPU_WARN = 1.5      # load1 / nproc
MEM_AVAIL_FRAC_WARN = 0.10   # MemAvailable / MemTotal
SWAP_USED_FRAC_WARN = 0.50   # (SwapTotal-SwapFree)/SwapTotal, SwapTotal>0
DISK_USE_PCT_WARN = 90       # any mount use%
PSI_AVG10_WARN = 20.0        # some avg10 on any resource
```

Warning shape: `{"kind": str, "severity": "warn"|"crit", "detail": str}`. Kinds:
`high_load`, `low_memory`, `swap_pressure`, `disk_full` (one per offending mount,
`crit` at ≥95%), `failed_units` (with names), `pressure` (per resource), `oom_recent`.

Result shape (mirrors `host_facts`):

```python
{
  "warnings": [ {kind, severity, detail}, ... ],   # empty list = healthy
  "facts": {
     "load1": float, "load5": float, "load15": float, "nproc": int|None,
     "mem_total_kb": int|None, "mem_available_kb": int|None,
     "swap_total_kb": int|None, "swap_free_kb": int|None,
     "disks": [ {"mount": str, "use_pct": int} ],
     "failed_units": [str],
     "psi": {"cpu": float|None, "memory": float|None, "io": float|None},  # some avg10
     "oom_recent": [str],
  },
  "stdout": str, "stderr": str, "exit_code": int,
  "truncated": bool, "stderr_truncated": bool,
}
```

`TRIAGE_SCHEMA`: `host` only (v1, thresholds fixed; `hosts` injected centrally).

Register in `TOOLS`. Description: "One round-trip health triage: load/cpu, mem/swap,
disk fullness, failed units, PSI pressure, recent OOM. Returns {warnings, facts, ...}."

# Item 4 — multi-host aggregation (P2, depends on item 5)

**Goal.** Turn N raw per-host blobs into a fleet answer:
`{common, outliers:[{host, ...}]}` — so "are these 10 hosts configured the same?"
is one glance, not ten diffs.

**Dependency.** Most useful on **structured** output. Pair with
`output_mode=parsed` (or `both`): comparing `parsed` structures avoids false
outliers from volatile stdout text (timestamps, ordering). Hence shipped after
item 5. Falls back to comparing `stdout` when no parser exists.

**Trigger.** New per-call boolean `aggregate`, injected centrally alongside
`hosts`/`output_mode` (server-level schema prop). Only meaningful with `hosts`.

**Algorithm (v1).**

1. For each per-host result, compute a **signature**: the comparable projection,
   in priority order — `parsed` if present, else `stdout`, else
   `{error, error_kind, exit_code}`. Canonicalize via
   `json.dumps(projection, sort_keys=True)`.
2. Group hosts by signature, preserving `hosts` order.
3. `common` = the largest group (ties broken by first appearance):
   `{"hosts": [...], "value": <projection>}`.
4. `outliers` = every host not in the common group, each
   `{"host", "value": <its projection>, "error_kind"?}`.
5. Result replaces the raw `results` list to save tokens:

```python
{
  "multi_host": True, "host_count": N, "aggregated": True,
  "signature_source": "parsed" | "stdout" | "error",  # what was compared
  "common": {"hosts": [...], "value": ...},
  "outliers": [ {"host", "value", ...}, ... ],         # empty = fleet uniform
}
```

When `aggregate` is falsy → current behavior unchanged (raw `results` list).

**Files.** `server.py` only:

- Inject `_AGGREGATE_PROP` (`{"type":["boolean","null"], "description": "..."}`)
  in `_augment_schema`.
- In `_call_tool` multi-host branch: after `_run_multi_host`, if
  `args.get("aggregate")` truthy → `result = aggregate_hosts(per)` (new helper).
  Keep `outcome=partial` accounting via `_multi_host_failed(per)` computed *before*
  aggregation.
- `aggregate_hosts(per)` pure function (unit-testable).

**Tests** (`tests/test_server.py`):

- 3 hosts identical `parsed` → `outliers == []`, `common.hosts` = all 3,
  `signature_source == "parsed"`.
- 1 differing host → `outliers` length 1 with its value; `common.hosts` length 2.
- no parser (stdout compare) → `signature_source == "stdout"`.
- a failed host (error) → grouped by error projection, appears as outlier with
  `error_kind`.
- `aggregate` falsy/absent → unchanged `{multi_host, host_count, results}` shape.
- tie-break determinism (two groups of equal size → first-appearing wins common).

**Acceptance.** `hosts + aggregate=true` returns a compact fleet diff; raw mode
untouched; pairs cleanly with `output_mode=parsed`.

**Open decisions to confirm before implementing** (small, but real):

- **Signature source priority** — proposed `parsed > stdout > error`. OK?
- **Outlier detail** — v1 ships the full projection per outlier; a structural
  field-level `diff` vs `common.value` is deferred. OK?
- **Drop vs keep raw `results`** — proposed: aggregation *replaces* `results`
  (token saving is the point). Alternative: keep both under a flag. OK to drop?
